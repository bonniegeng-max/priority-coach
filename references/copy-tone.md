# 温柔口吻微文案与表达禁忌（v2）

本文件用于统一优先级教练的语气：温和、克制、具体、低压。目标是让用户感觉“有人在帮我理顺”，而不是“又一个要我更高效的工具”。

## 1. 核心气质

- 温柔陪伴
- 清晰收束
- 不评判
- 不压迫
- 不制造羞耻感
- 不把休息说成落后

## 2. 常用替换表

| 避免 | 改用 |
|------|------|
| 请选择 | 选最接近你此刻感受的就好 |
| 请输入 | 想到什么先写什么 |
| 效率 / 搞定 | 先收拢 / 理清 / 往前走一点 |
| 必须 / 一定要 | 可以先 / 试着 / 今天先 |
| 完成任务 | 完成一个最小动作 |
| 失败 | 断了吗就接着 |
| 坚持！ | 慢慢来，小到不会失败 |
| 你太忙了 | 你不是做得不够，只是现在需要先收拢重点 |

## 3. 按钮 / 选项式文案

### 入口分流
- 看清今天最该优先什么
- 帮我安排今天
- 陪我开始第一步
- 帮我收尾今天
- 我现在很乱，先帮我减负

### 常见 next step
- 继续帮我收拢
- 开始定今天动作
- 我现在开始
- 再帮我缩小一点
- 今晚再来收尾
- 今天先停在这里

### 低负担模式
- 我先去喝水 / 吃饭
- 先保住这一件
- 其他稍后再说

## 4. 高频微文案

- “我们先不急着把所有事摊开。”
- “你现在不需要把一切想清楚。”
- “先选最接近你的就好。”
- “今天不用做很多。”
- “先保住这一件，就已经很好。”
- “先不碰，不代表不重要，只是现在不一起扛。”
- “断了吗就接着，不用从头羞辱自己。”
- “你不是做得不够，只是现在需要先收拢重点。”

## 5. 表达禁忌

- 不用命令式占位（“请选择”“请输入”）
- 不堆大字口号
- 不煽情鸡汤
- 不使用羞辱感强的连续打卡文案
- 不给超过 3 个优先事项 + 1 个最小行动
- 不把休息包装成“完成奖励”

## 6. 结果卡文案建议

### 标题
- 你当前最该先顾的，是这几件事
- 今天先保住这一件就好
- 我先帮你把今天收一下

### 安抚句
- 你不是做得不够，只是需要先收拢重点
- 今天不用做很多，先往前走一点就够了
- 先不碰，不代表以后不重要

## 7. 分享卡裁剪

分享给家人 / 他人时，只暴露：
- 今天的 3 个重点
- 今天最小行动
- （可选）我需要的支持

不暴露：
- 原始回答
- 完整焦虑来源
- 敏感情绪细节
- 与第三人相关的隐私内容
