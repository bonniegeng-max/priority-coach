# 温柔口吻微文案与表达禁忌

本文件用于生成任何面向用户的页面、结果卡、分享卡时，统一"优先级教练"的语气与视觉调性。灵感源自 DESIGN.md（暖陶土 + 鼠尾草绿 + 米白底），这里只保留"文案层"规范；视觉参数见原 DESIGN.md，不在此重复。

## 1. 核心气质

温柔陪伴、不评判、不压迫、不制造"必须高效"的压力。让用户感觉"有人在帮我理顺，而不是催我完成"。

## 2. 用词替换表

| 避免 | 改用 |
|------|------|
| 请选择 | 选最接近你此刻感受的就好 |
| 请输入 | 想到什么先写什么 |
| 效率 / 搞定 | 先收拢 / 理清 |
| 必须 / 一定要 | 可以先 / 试着 |
| 你太忙了 | 你不是做得不够，只是需要先收拢重点 |
| 完成任务 | 完成一个最小动作 |
| 失败 | 断了吗就接着，下次再来 |
| 坚持！ | 慢慢来，小到不会失败 |

## 3. 高频微文案

- 首页副标：帮你看清自己、家庭和工作的重点
- 首页说明：用 5 个小问题，帮你看清现在最该优先处理的事
- 隐私安心：你的内容默认仅自己可见
- 5 问进度：别急，我们一题一题来
- 结果标题：你现在最该先顾的，是这 3 件事
- 结果安抚：你不是做得不够，只是现在需要先收拢重点
- 最小行动说明：今天不用做很多。先完成一个最小动作，就已经是在往前走
- 先不碰说明：先不碰，不代表不重要。只是现在不需要同时扛起全部

## 4. 表达禁忌

- 不用命令式占位（"请选择""请输入"）
- 不堆大字口号、不煽情鸡汤
- 不出现"60%""3/5 完成"式百分比压迫（进度用条 + "第 X/5 题"）
- 不把红色当主色/强调（红色传递紧迫，与调性冲突）
- 不给超过 3 个优先 + 1 个最小行动的负担

## 5. 分享卡裁剪

分享给家人/他人时只暴露：
- 今天的 3 个重点
- 今天最小行动
- （可选）"我需要的支持"一句

不暴露：原始回答、完整焦虑来源、敏感情绪细节。
