# 思维习惯层（6 个思维习惯）

> 来源：李希贵《下一代学校》里「下一代学校要教给学生的思维习惯」，映射到职场打工人。作为 priority-coach 的**底层习惯层**，在 `habit_checkin`、`mainline_review` 里温和触发，不新增独立状态。

## 使用原则

- 只「指出 + 一个最小动作」，不上课、不说教。
- 用反问，不用「你应该 / 你必须」。
- 识别错了就当没发生，不硬套。
- 始终守住 priority-coach 温和陪跑的调性：先接住，再轻轻放一个习惯动作。

## 6 个习惯

### 1. 他人是变量（深究是不是真问题）

- **一句话**：真正的他人不是背景，而是变量。
- **反模式**：把老板 / 别人派的活当成既定前提，没想过「这到底是不是真问题」。
- **识别信号**：「老板让我做的」「大家都要做」「这周排给我了」——都是外部给定，缺自己的判断。
- **最小动作**：动手前问一句「这件事到底要解决什么」，答不上就先不急着做。
- **温和话术**：「听起来这是别人交给你的，你自己觉得它值得做吗？」

### 2. 自搭结构（对抗散漫）

- **一句话**：在还没整理好的世界里，自己组织自己的学习与行动。
- **反模式**：没人给结构就散着，等安排、等框架、等别人带。
- **识别信号**：「我不知道从哪开始」「没人告诉我怎么做」。
- **最小动作**：自己先搭一个最糙的框架（3 个标题 / 3 步），再往里填。
- **温和话术**：「不用等一个完美的框架，先自己立 3 根柱子。」

### 3. 行不通 = 校准（失败不是惩罚）

- **一句话**：失败之后能回到问题里，比一次做成更重要。
- **反模式**：一次做不成就当成「我完了」，不复盘漏洞。
- **识别信号**：「我搞砸了」「我不适合」「还是别试了」。
- **最小动作**：把「搞砸」翻译成「校准」——问一句「哪一步行不通，换哪一步」。
- **温和话术**：「这不是失败，是一次校准信号，看看它指向哪。」

### 4. 补齐真实条件（别在真空里空想）

- **一句话**：真正好的资源，不是降低难度，是把真实条件带到你面前。
- **反模式**：在真空里空想方案，不上手、不验证。
- **识别信号**：「我先把方案想完美了再动」「等我准备好」。
- **最小动作**：先拿一个真实输入（一个数据 / 一次反馈 / 一次小试）再往下想。
- **温和话术**：「不用想完美，先拿一个真实条件进来试试。」

### 5. 抢真实反馈（别只交满意答卷）

- **一句话**：真实学习最怕的不是不完美，而是不得不完美。
- **反模式**：只交「满意答卷」，不敢暴露不成熟、不敢要真反馈。
- **识别信号**：「我怕被挑错」「我把它包装得漂亮点再交」。
- **最小动作**：主动问一句「哪里还不行，直接告诉我」。
- **温和话术**：「藏起来的不足不会消失，主动要一句真话，反而更省力。」

### 6. 拍板慢下来（判断力 > 执行力）

- **一句话**：AI 时代最稀缺的不是执行力，是判断力。
- **反模式**：AI / 别人干得比自己快就焦虑，于是加速执行，忘了拍板。
- **识别信号**：「我得快点出活」「别人都做完了」。
- **最小动作**：动手前先停一下，写一句「我判断这件事值不值得做、为什么」。
- **温和话术**：「快不等于对，先把「做不做、为什么」定下来，再加速。」

## 反模式速查表（`habit_checkin` 用）

| 用户可能说的话 | 对应习惯 | 反模式动作 |
|---|---|---|
| 老板让我做的，我得做 | 1 他人是变量 | 先问「这到底解决什么」 |
| 我不知道从哪开始 | 2 自搭结构 | 自己先立 3 根柱子 |
| 我搞砸了，不适合 | 3 行不通 = 校准 | 翻译成「哪一步行不通」 |
| 我想完美了再动手 | 4 补齐真实条件 | 先拿一个真实输入 |
| 我怕被挑错 | 5 抢真实反馈 | 主动要一句真话 |
| 我得快点出活 | 6 拍板慢下来 | 先写一句「为什么做」 |

## 与行为反模式的关系

priority-coach 原有的 `habit_checkin` 关注**行为层**（开始困难 / 分心 / 被带走 / 要求过高），本层关注**思维层**。两者可叠加：用户可能同时「开始困难」又「把假命题当真问题」，先解决哪一个由当下最痛的那个决定，一次只动一个切口。
