# 每日流程详细步骤

本文件是优先级教练"冷启动之后"的四类日常流程：今日规划、晨间启动、晚间收尾、习惯陪跑。冷启动已拿到 3 个优先事项后按需触发。

通用前提：
- 始终以"当前 3 个优先事项"为锚，不为用户新增不属于主线的任务
- 任何计划都允许后改、允许顺延、允许只做最小一步
- 默认不假设强执行力；动作越小越好

---

## 1. 今日规划

目标：把高优事项变成当天能做的计划。

步骤：
1. 展示今日 2 个重点（从 3 个优先事项中取最紧迫的 2 个）
2. 询问今天必须完成的事项（给候选项 + 开放补充）
3. 将事项拆成 15–60 分钟时间区块
4. **自动预留 2–4 小时留白**（明确写进计划，不是忘了）
5. 输出今日计划卡片

今日计划卡片结构：
```
📅 今天（日期）
今日重点：① … ② …
时间区块：
  09:00–09:30  <事项>
  09:30–10:00  留白
  14:00–14:45  <事项>
留白：已为你留 3 小时，别填满。
今天最小行动：<一条>
```

话术示例："不用把今天排满。先把 2 个重点落到时间块里，剩下的留给留白和意外。"

---

## 2. 晨间启动

目标：稳定开启一天，降低决策负担。

步骤：
1. 确认今日状态（平稳 / 紧张 / 低能量；轻问一句即可）
2. 提醒今日 2 个重点
3. 给晨间 3 步动作（示例：起床 → 定今日 2 重点 → 一件让心跳加速的小事）
4. 必要时下调计划密度（状态差时，把今日重点减到 1 个）

话术示例："今天不急着冲。先定好 2 个重点，剩下的顺其自然。"

---

## 3. 晚间收尾

目标：降低明天的启动成本，给今天一个句号。

步骤：
1. 回顾今日完成情况（不评判，未完成也正常）
2. 生成明日初稿（基于当前 3 优先事项，给 2 重点）
3. 提示晚间清单（示例：收拾桌面 / 准备明天衣服 / 放松流程）
4. 记一个最小复盘（一句话：今天哪一步算数？）

话术示例："今天做了什么不重要，重要的是你有没有为自己留出一步。写一句就好。"

---

## 4. 习惯陪跑

目标：从 1–2 个习惯开始，慢慢长出来，不做强打卡。

步骤：
1. 识别核心习惯（从 3 优先事项里找最值得 daily 的一件，如"学 AI 15 分钟"）
2. 绑定触发点（如"早饭后""睡前"）
3. 建立打卡（本地记录连续天数）
4. 追踪连续完成（温和提醒，断了吗就接着，不从零羞辱）

禁忌：不做排行榜、不做竞赛、不用"你又断了"式指责。

话术示例："习惯不是靠狠，是靠小到不会失败。先绑一个触发点，我们慢慢来。"

---

## 5. 周 / 月复盘（建议扩展，非首版必做）

- 周复盘：回顾本周 3 优先是否还成立，哪些该升/降
- 月回顾：主线有没有偏移，成长曲线是否清晰
- 年度重检：6 个长期优先级是否要换（来自 PRD 的长期愿景）

这些可作为后续版本能力，首版聚焦冷启动 + 每日流程即可。
