# 状态路由规则

本文件定义优先级教练的入口判断逻辑。目标不是“分类得很学术”，而是尽快把用户送进**当下最合适的一条流**。

## 1. 路由优先级

按下面顺序判断，一旦命中就进入该状态：

1. **高风险 / 危机表达**
   - 例如：自伤、自杀、他伤、严重暴力、明显医疗或精神危机
   - 处理：不要继续走普通 priority coaching；先鼓励联系当地紧急支持、可信任的人或专业帮助

2. **本地记录意图**
   - 例如：查看上次结果、保存这次、删掉记录、导出记录
   - 处理：先调用 `scripts/record.py` 对应命令，再决定是否返回原状态

3. **明确说要收尾 / 复盘 / 结束今天** → `evening_wrap`

4. **明确说要开始 / 拖延 / 开不了工 / 陪我迈出第一步** → `morning_start`

5. **明确说要安排今天 / 做今日计划 / 排今天** → `today_plan`

6. **明确说自己总在重复某种模式里卡住**
   - 例如：总拖延、总分心、总被别人带走、总对自己太狠
   - 进入 `habit_checkin`

7. **明显过载 / 不想选 / 太乱太累 / 连判断都不想做** → `overwhelmed_mode`

8. **其他“想理清重点、很多事缠在一起、找不到主线”** → `cold_start`

## 2. 各状态典型触发语

### `cold_start`
- 我最近很乱
- 感觉每天很忙但不知道忙了什么
- 我不知道现在最重要的是什么
- 很多事情缠在一起

### `priority_select`
- 我已经有几个方向了，帮我排一下
- 这几个里哪个先做
- 我只想先选一个

### `today_plan`
- 帮我安排今天
- 给我一个今天的轻计划
- 我想把今天过得清楚一点

### `morning_start`
- 我准备开始了
- 但我还是在拖
- 你陪我迈出第一步

### `evening_wrap`
- 今天差不多结束了
- 帮我收一下今天
- 我想复盘一下今天，但不想自责

### `habit_checkin`
- 我总是开始不了
- 我老是做着做着分心
- 我总被别人带着走
- 我对自己要求太高

### `overwhelmed_mode`
- 我太累了
- 我不想再选了
- 我现在脑子是糊的
- 我什么都不想想

## 3. 从一个状态切到另一个状态

### `cold_start` → `priority_select`
条件：已经归纳出 3–7 个候选方向，用户愿意选择 / 比较

### `priority_select` → `today_plan`
条件：已经确定今天第一优先是什么

### `today_plan` → `morning_start`
条件：用户已经有最小动作，并表示“准备开始 / 现在开始”

### `today_plan` → `evening_wrap`
条件：用户说“晚上再来收尾”或当天流程已自然结束

### 任意状态 → `overwhelmed_mode`
满足任一：
- 用户明确表示不想再答 / 不想选 / 太累
- 连续两轮无法推进
- 语言中出现明显自责、耗竭、麻木、拒绝继续

## 4. 路由不清时怎么做

如果信息不足，不要追着问开放题。优先使用一个小分流：

> 你现在更需要哪一种帮助？
> - 看清今天最该优先什么
> - 帮我安排今天
> - 陪我开始第一步
> - 帮我收尾今天
> - 我现在很乱，先帮我减负

如果用户仍然不想选，直接切 `overwhelmed_mode`。

## 5. next step 规则

每个状态结束时都要给出一个明确 next step。

示例：
- `cold_start`：继续帮我收拢 / 我先选这 3 个
- `priority_select`：开始定今天动作 / 先保住这一件
- `today_plan`：我现在开始 / 再缩小一点 / 今晚来收尾
- `morning_start`：我开始了 / 我卡住了 / 换成更小一点
- `evening_wrap`：保存成明天起点 / 结束今天
- `habit_checkin`：压到 5 分钟版本 / 我先试一次
- `overwhelmed_mode`：我先去吃饭 / 再帮我缩小 / 今天先停在这里
